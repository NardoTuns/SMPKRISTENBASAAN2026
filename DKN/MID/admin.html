📥 Import Excel

Unggah file Excel dengan format template. Aplikasi otomatis mengenali sheet: Siswa (data siswa) dan sheet bernama kode mapel seperti MTK, IPA (nilai). Format lama (sheet Siswa + Nilai) dan file DKN/Leger tetap bisa dibaca. Sebelum disimpan, ringkasan & peringatan ditampilkan dulu.

📄 Download Template Excel

Template lengkap sudah berisi daftar siswa & nilai yang ada sekarang, sehingga cukup diisi/diubah lalu diimport kembali.
